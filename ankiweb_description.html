Every Chinese character you're learning on one screen, by HSK level, coloured by how well you know it. Start Tools → Hanzi Grid → ⚙ Settings → pick your deck and fields → Save. Using the Anki-xiehanzi HSK deck? Skip Settings. Features
  • Colours: new, learning, young, mature, well known, mastered.
  • Views: Characters, Words, Measure words, Grammar, Reading.
  • Click a character to see all its words.
  • Progress per level, "+N this week", summary on the deck list.
  • Five colour themes, Hei/Song/Kai fonts, three sizes.
  • Offline. Never changes your cards.

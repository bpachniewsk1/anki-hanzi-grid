# Classifier data

`classifiers.json` lists, for 1,500-odd words, the classifiers (measure
words) they take, plus the pinyin and a gloss for each classifier. It was
extracted from the "CL:" notes in **CC-CEDICT**, the community-maintained
Chinese–English dictionary (https://cc-cedict.org/ , download from
https://www.mdbg.net/chinese/dictionary?page=cc-cedict ), licensed under
CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). This file
keeps that licence. Only the word → classifier pairs, the classifiers'
pinyin and one gloss each were taken; the dictionary itself is not bundled.

CC-CEDICT marks classifiers mainly for concrete nouns. A word without an
entry here usually takes 个, or is abstract.
